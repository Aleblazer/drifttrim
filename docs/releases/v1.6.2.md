**DriftTrim is the new name for ZMK Volume Fader.** This first public DriftTrim release adds QMK/VIK and generic MIDI faders alongside ZMK HID, and gives the mixer a resizable, two-column layout. These notes cover everything since v1.5.0.

### QMK/VIK and MIDI faders

- Mix ZMK HID, QMK/VIK, generic MIDI and virtual faders in one layout. Physical faders still control Windows outputs, individual apps or categories and use the existing volume caps, calibration and soft takeover.
- Each MIDI input appears once in **Layout → Add physical fader**. Select the device, sweep a fader and capture its range. New bindings default to **14-bit CC**; the separate **Input profile** selector also offers **7-bit CC** and **14-bit CC (QMK/VIK heartbeat)**. Editing a source restores its saved profile.
- DriftTrim combines coarse and fine MIDI messages before applying volume, retaining the controller's full resolution through calibration. It discovers MIDI inputs as they connect and opens only those used by a configured fader or active capture. **Options → Diagnostics** helps troubleshoot inputs that cannot be opened.
- With the heartbeat profile and compatible firmware, a missing fader goes offline without forcing its target volume to zero. Soft takeover can re-engage when readings resume. The standard MIDI profiles work with controllers that send only on movement.
- The [QMK/VIK setup guide](https://github.com/Aleblazer/drifttrim/blob/v1.6.2/docs/qmk-midi.md) documents the separate `midi_fader` firmware configuration: one to four faders per ADS1115 module, optional modules at different I²C addresses, split and non-split setups, and up to 32 faders in the documented split mapping. The Windows release does not include a firmware binary.

### Resizable mixer

- Drag the main window's edges or maximize it. Faders automatically use two columns when there is room, reading left to right in your existing layout order. Narrower windows use one column.
- Shorter windows scroll while **Refresh**, **Layout** and **Options** stay visible. Editing the layout keeps the window size, and reopening from the tray preserves maximized mode.

### Download and upgrade

- Use **`DriftTrim-1.6.2-win-x64.msi`** for an installed copy or **`DriftTrim-1.6.2-win-x64.exe`** for a portable copy. Both are self-contained and require Windows 10 version 2004 (build 19041) or later, or Windows 11, on x64. `SHA256SUMS.txt` covers both downloads.
- Exit the previous copy from the system tray before upgrading or running the portable EXE. The MSI retains the previous install location and upgrade identity. Settings stay in `%APPDATA%\ZmkVolumeFader\settings.v2.json`; the app backs up older settings when migrating to the format that stores MIDI bindings. Older builds cannot read the migrated format.
- The [renamed repository](https://github.com/Aleblazer/drifttrim) retains its history, issues and earlier releases. Existing ZMK hardware continues to use the same HID protocol.

The Windows build and logic tests, MIDI setup and responsive layout smoke checks, and packaged MIDI enumeration passed. Full hardware validation across the documented VIK configurations and an installed MSI upgrade from v1.5.0 remain unverified. MIDI support is input-only and uses absolute MIDI 1.0 CC; it does not send motor-fader feedback or handle relative encoders.
